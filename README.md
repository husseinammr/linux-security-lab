# 🛡️ Linux Security Lab | مختبر أمن لينكس

**الإصدار 1.0.0**

منصة تعليمية تفاعلية متخصصة في أمن أنظمة Linux، تجمع بين التعلم النظري والتطبيق العملي في بيئة افتراضية آمنة تعمل بالكامل داخل المتصفح.

يهدف المشروع إلى مساعدة المتعلمين على فهم أنظمة Linux وتطبيق مفاهيم أمن المعلومات من خلال دروس تفاعلية، وطرفية افتراضية، ومحاكاة صلاحيات الملفات والمستخدمين، وتحليل السجلات، وأمن الشبكات، والتحقيقات الأمنية.

لا يحتاج المشروع إلى خادم خلفي أو قاعدة بيانات أو تثبيت بيئة Linux على الجهاز.

# 📚 الأقسام التعليمية

تتكون المنصة من سبعة أقسام رئيسية:

### 01. أساسيات Linux
**Linux Fundamentals**

التعرف على بنية نظام الملفات وإدارة الملفات والمجلدات واستخدام الأوامر الأساسية.

الموضوعات:
- Linux Filesystem Hierarchy.
- التنقل بين المجلدات.
- إنشاء الملفات وإدارتها.
- قراءة وتعديل الملفات.
- البحث عن الملفات والمحتويات.
- استخدام Pipes.
- الأوامر الأساسية.

الأوامر:
`ls`, `cd`, `cat`, `head`, `tail`, `grep`, `find`, `stat`

### 02. صلاحيات الملفات
**File Permissions**

فهم نظام الصلاحيات وآليات التحكم بالوصول إلى الملفات والمجلدات.

الموضوعات:
- Read, Write, Execute (rwx).
- chmod.
- chown.
- chgrp.
- umask.
- SUID وSGID.
- Sticky Bit.
- Access Control Lists (ACLs).
- التحويل بين الصيغ الرقمية والرمزية.

الأدوات:
- Permission Simulator.
- Permission Calculator.
- Terminal Simulator.

### 03. المستخدمون والمجموعات
**Users & Groups**

دراسة إدارة الحسابات والمجموعات والتحكم بالامتيازات داخل Linux.

الموضوعات:
- إدارة حسابات المستخدمين.
- ملفات `/etc/passwd` و`/etc/shadow`.
- إدارة المجموعات.
- User Ownership.
- الفرق بين su وsudo.
- Privilege Escalation.
- تدقيق الحسابات وتقييد الوصول.

الأوامر:
`id`, `groups`, `usermod`, `gpasswd`, `passwd`, `sudo -l`

### 04. أمن الشبكات
**Network Security**

التعرف على إعدادات الشبكة ومراقبة الاتصالات والخدمات المفتوحة وتقليل المخاطر الأمنية.

الموضوعات:
- Network Interfaces.
- IP Addressing.
- Routing.
- DNS.
- Open Ports.
- Listening Services.
- Network Connections.
- تقليل التعرض للشبكة.

الأوامر:
`ip addr`, `ip route`, `hostname`, `ping`, `ss -tulpn`, `ss -tn`, `systemctl`

### 05. تحليل السجلات
**Log Analysis**

التعرف على سجلات النظام وتحليل الأحداث الأمنية واكتشاف الأنشطة غير الطبيعية.

الموضوعات:
- Linux Log Files.
- Authentication Logs.
- Failed Login Attempts.
- Suspicious Activity.
- Log Inspection.
- Digital Evidence.
- حماية سلامة السجلات.

الملفات والأوامر:
`/var/log/auth.log`, `/var/log/syslog`, `journalctl`, `last`, `lastb`, `dmesg`, `grep`, `sort`, `uniq`

### 06. التحقيقات الأمنية
**Security Investigation**

تطبيق منهجية التحقيق الأمني من خلال سيناريوهات تحاكي مشكلات واقعية في أنظمة Linux.

تعتمد منهجية التحقيق على المراحل التالية:

**Incident → Evidence → Diagnosis → Remediation → Verification**

يتضمن القسم خمسة سيناريوهات عملية تغطي الصلاحيات والمستخدمين والشبكات والسجلات.

### 07. بنية Linux وتاريخه
**Linux Architecture & History**

التعرف على تاريخ Linux وبنيته الداخلية وآلية عمل مكوناته.

الموضوعات:
- Unix وGNU وLinux.
- Linus Torvalds.
- Linux Distributions.
- Kernel vs Distribution.
- Kernel Space وUser Space.
- Boot Process.
- Process Management.
- Everything is a File.
- Package Management.
- System Updates.

الأوامر:
`lscpu`, `free -h`, `lsblk`, `df -h`, `uptime`, `ps aux`, `dmesg`, `systemctl list-units`

# ⚙️ المميزات الرئيسية

## 1. الدروس التفاعلية

تحتوي المنصة على **59 درساً تعليمياً** موزعة على الأقسام السبعة.

يتضمن كل درس:
- شرحاً للمفهوم.
- رسماً توضيحياً.
- مثالاً عملياً.
- أوامر للتجربة.
- نصائح وتحذيرات أمنية.

## 2. محاكي الصلاحيات

أداة تفاعلية لتعلم وفهم صلاحيات Linux.

المميزات:
- التحكم بصلاحيات Owner وGroup وOthers.
- عرض الصلاحيات بصيغة Symbolic.
- عرض الصلاحيات بصيغة Octal.
- عرض التمثيل الثنائي Binary.
- إنشاء أوامر chmod تلقائياً.
- دعم SUID وSGID وSticky Bit.
- تحديث النتائج مباشرة عند تغيير الصلاحيات.

## 3. الطرفية الافتراضية
**Terminal Simulator**

طرفية تعليمية تحاكي بيئة Linux وتدعم **63 أمراً** ضمن نظام ملفات افتراضي.

### إدارة الملفات

`pwd`, `cd`, `ls`, `tree`, `stat`, `find`, `cat`, `touch`, `mkdir`, `cp`, `mv`, `rm`, `ln`

### معالجة النصوص والسجلات

`grep`, `head`, `tail`, `wc`, `sort`, `uniq`

### إدارة الصلاحيات

`chmod`, `chown`, `chgrp`, `umask`, `getfacl`, `setfacl`

### إدارة المستخدمين

`whoami`, `id`, `groups`, `su`, `sudo`, `usermod`, `gpasswd`, `passwd`

### معلومات النظام والأجهزة

`ps`, `who`, `w`, `last`, `lastb`, `lastlog`, `uname`, `df`, `du`, `lscpu`, `free`, `lsblk`, `uptime`

### الخدمات والسجلات

`systemctl`, `journalctl`, `dmesg`, `getcap`, `crontab`

### أوامر الشبكات

`ip`, `hostname`, `ping`, `ss`, `netstat`

### خصائص الطرفية

- محاكاة نظام ملفات افتراضي.
- تطبيق قواعد الصلاحيات على الملفات.
- محاكاة المستخدم الجذر Root والمستخدمين العاديين.
- دعم ACLs والروابط الرمزية.
- محاكاة العمليات والخدمات والاتصالات.
- التعامل مع ملفات الحسابات والسجلات.
- دعم الأنابيب البسيطة Single Pipes.
- محاكاة تنفيذ الأوامر دون التأثير على الجهاز الحقيقي.

**ملاحظة أمنية:** الطرفية محاكية بالكامل، ولا تنفذ أوامر Linux حقيقية على جهاز المستخدم. تتم معالجة جميع الأوامر بواسطة JavaScript داخل التطبيق.

## 4. التحقيقات الأمنية
**Security Investigations**

يتضمن المشروع خمسة سيناريوهات تفاعلية تحاكي مشكلات أمنية واقعية.

| المعرّف | القسم | السيناريو |
|---|---|---|
| INV01 | Permissions | ظهور خطأ 403 بعد تحديث التطبيق |
| SC01 | Permissions | إمكانية قراءة ملف إعدادات من حسابات غير مصرح لها |
| INV02 | Users & Groups | امتلاك حساب خدمة صلاحية sudo |
| INV03 | Network Security | خدمة Cache تستمع على 0.0.0.0:6379 |
| INV04 | Log Analysis | محاولات SSH فاشلة يتبعها تسجيل دخول ناجح |

تتضمن التحقيقات:
- جمع الأدلة وتحليلها.
- تشخيص المشكلة الأمنية.
- تطبيق المعالجة المناسبة.
- التحقق من نجاح الحل.
- اكتشاف الأضرار الجانبية المحتملة.
- إنشاء تقرير بالتحقيق.

تعتمد نتائج التحقيق على الحالة الفعلية للنظام الافتراضي، وليس فقط على الأوامر التي ينفذها المستخدم.

كما تتم استعادة حالة النظام عند مغادرة التحقيق أو إعادة ضبطه.

# ⚠️ القيود المعروفة

على الرغم من أن المشروع يوفر محاكاة تعليمية متقدمة لبيئة Linux، توجد بعض القيود:

1. الطرفية بيئة تعليمية افتراضية وليست Terminal حقيقية.
2. لا يتم تنفيذ أوامر Linux الحقيقية على الجهاز.
3. لا تدعم الطرفية إعادة توجيه المخرجات باستخدام `>` و`>>`.
4. لا تدعم ربط الأوامر باستخدام `;` أو `&&` أو `||`.
5. لا يتم إرسال حزم شبكة حقيقية عند استخدام أوامر الشبكات المحاكية.
6. أوامر `nano` و`vim` لا توفر تحريراً فعلياً لمحتويات الملفات.
7. بعض الأدوات مثل `chattr` و`lsattr` و`visudo` غير مدعومة داخل المحاكي.
